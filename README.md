# Day 2 - Prompt Engineering

## Overview
Today I explored Prompt Engineering and learned how the quality of a prompt directly impacts the quality of AI-generated responses.

## What is Prompt Engineering?
Prompt Engineering is the practice of writing clear, specific, and structured instructions to get better results from AI tools like Claude.

## Experiment

### Weak Prompt
Design an algorithm.

### Output
- Generic response
- Limited details
- No specific context
- Basic explanation

---

### Engineered Prompt
Design an algorithm to find the shortest path in a weighted graph using Dijkstra's Algorithm. Include:
- Step-by-step explanation
- Pseudocode
- Time complexity analysis

### Output
- Detailed explanation
- Structured response
- Relevant algorithm
- Better learning experience

---

## Key Learnings

✅ Be Clear

✅ Be Specific

✅ Provide Context

✅ Define Output Format

✅ Add Constraints When Needed

---

## Why Prompt Engineering Matters

- Better AI Responses
- Higher Accuracy
- Saves Time
- More Useful Outputs
- Improved Productivity

---

## Conclusion

A small improvement in a prompt can create a significant improvement in the final output.

**Better Prompts → Better Results 🚀**
